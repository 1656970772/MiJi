# 2026-06-08 Graphify / Codex 安装记录

- 用户需求：确认本项目此前用于生成知识库图谱的开源项目名称，并为 Codex 安装对应工具。
- 本地证据：项目中已有 `raw/graphify-out/graph.json`、`raw/graphify-out/graph.html`、`raw/graphify-out/GRAPH_REPORT.md`；历史对话记录多次提到 `graphify add`、`graphify.transcribe`、`raw/graphify-out`。
- 公开来源核对：官方站点与 GitHub 仓库说明该项目名为 Graphify，PyPI 包名为 `graphifyy`，CLI 命令仍为 `graphify`，支持 Codex 集成命令 `graphify codex install`。
- 安装动作：在 Python 3.13 环境执行 `python -m pip install --upgrade "graphifyy[chinese]"`，安装版本为 `graphify 0.8.35`。
- Codex 集成：执行 `graphify codex install`，写入 `AGENTS.md` 并创建 `.codex/hooks.json`；随后把新增 Graphify 规则改为中文，并修正图谱路径为 `raw/graphify-out/graph.json`。
- 验证结果：`graphify --version` 返回 `graphify 0.8.35`；`graphify query "这个项目的知识图谱工具是什么？" --graph raw\graphify-out\graph.json --budget 800` 能正常返回节点和关系；`git diff --check` 仅出现 Windows 换行提示，无真实 whitespace 错误。
- 临时取舍：本次只安装了中文分词扩展，没有安装 `video` 转写扩展；如后续继续用 `graphify.transcribe` 处理视频或音频，可再安装 `graphifyy[video]`。
